### 🛡️ Toxicity Detection

> Production-oriented local text moderation platform combining a Flask inference API with a Chrome Manifest V3 extension.

🔗 **Repository:**
https://github.com/AdityaCShekhar/Toxicity-Detection

**Highlights**

* 🧠 TensorFlow / Keras inference
* 📚 Persisted vocabulary
* 🎯 Configurable classification threshold
* 🔄 Single and batched classification APIs
* 🛑 Input limits and validation
* 🐳 Docker deployment
* 🔫 Gunicorn production server
* ❤️ Health checks
* 📖 OpenAPI documentation
* 📊 Structured logging and response timing
* 🧪 Model evaluation tooling
* 🔁 Unit tests and CI coverage

The extension scans page text, batches requests to the local API, and blurs content classified as toxic.
